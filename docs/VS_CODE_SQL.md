# SQL with VS Code — V1

1. Open the repository in VS Code.
2. Use the included `data/commerce/commerce_lab.db` file.
3. Install any trusted SQLite viewer/extension in VS Code.
4. Inspect the tables before writing queries.
5. Save your work in the submission path shown by each challenge.
6. Keep a short `README.md` with assumptions for advanced cases.

No database server is required for the included SQLite lab.
