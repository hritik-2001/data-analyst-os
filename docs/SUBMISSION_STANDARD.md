# Submission Standard

For every meaningful task, submit evidence to GitHub.

## SQL
- `.sql` query
- optional `README.md` for assumptions
- result export for project-level work

## Python
- `.py` or `.ipynb`
- output tables/figures when relevant
- short note on assumptions and validation

## Power BI
- `.pbix`
- screenshots or PDF export for portfolio projects
- metric dictionary for advanced/professional work

## Excel
- `.xlsx`
- control/check sheet for reconciliation or advanced projects
- short README for assumptions

## Project minimum

Every project should show:
1. Problem framing
2. Data sources and grain
3. Cleaning/validation
4. Analysis
5. Deliverable
6. Findings
7. Recommendation
8. Known limitations
